# S2Internal — сообщения об ошибках

[English](README.md) | **Русский**

Сообщения об ошибках и логи мода S2Internal.

**[Сообщить о проблеме](https://github.com/mmnt1337/S2Internal-Reports/issues/new?template=bug-ru.yml)** · [Уже известные проблемы](https://github.com/mmnt1337/S2Internal-Reports/issues)

## Как сообщить

1. Войдите в GitHub или создайте бесплатный аккаунт.
2. Нажмите **Сообщить о проблеме** и напишите короткий заголовок, например «ESP перестаёт обновляться».
3. Опишите, что вы сделали, что пошло не так и что должно было произойти.
4. Укажите версию мода или название скачанного архива и приложите логи по инструкции ниже.
5. Нажмите **Submit new issue** — кнопку отправки обращения.

Пример: «Включил ESP и миникарту. Через несколько минут метки ESP перестали обновляться. Выключение и повторное включение ESP не помогло».

Для каждой проблемы создавайте отдельное обращение. Если такая проблема уже описана, добавьте свои подробности и логи комментарием к тому обращению.

## Как приложить логи

**Приложите логи за время возникновения проблемы. Без них мы обычно не можем определить причину.**

1. Нажмите **Win + R** — клавишу со значком Windows и букву R.
2. Вставьте `%LOCALAPPDATA%\S2Internal` и нажмите **Enter**.
3. Найдите **s2internal.log**. Если Windows скрывает расширение, файл будет называться **s2internal**. Если он очень большой, возьмите самый свежий по дате изменения файл **s2internal_….log**.
4. При вылете или зависании также соберите файлы **crash_metrics_….log**, изменённые примерно в момент проблемы. Отсортируйте папку по **Дате изменения**, чтобы найти их.
5. Перетащите файлы в поле **Логи** в обращении или нажмите на него для выбора файлов. Дождитесь окончания загрузки.

Если лаунчер не запускает мод, приложите **launcher.log** из папки, где лежит **S2InternalLauncher.exe**. Скопируйте его до следующей попытки: повторный запуск лаунчера заменяет этот файл.

Чтобы приложить несколько файлов вместе, выделите их копии, нажмите правой кнопкой и выберите **Сжать в ZIP-файл** (Windows 11) или **Отправить → Сжатая ZIP-папка** (Windows 10). Приложите ZIP.

## Полезные подробности

Укажите способ запуска — лаунчер или ReShade, включённые функции и частоту возникновения проблемы. При низком FPS укажите примерный FPS до/после и модель видеокарты. Скриншоты проблемы или сообщения об ошибке можно приложить в поле **Подробности**.

Обращения и вложения видны всем. Перед отправкой проверьте файлы на наличие личных данных.
